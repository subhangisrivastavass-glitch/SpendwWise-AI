# SpendWise AI

## About the Project
SpendWise AI is an AI-powered personal finance platform built using Python and Streamlit to help users understand and manage their spending.

## Features
- Expense analysis and budget health tracking
- Spending forecasts and anomaly detection
- Financial goal tracking
- Interactive data visualizations
- AI-powered financial chatbot using Gemini AI

## Technologies Used
- **Python** — Application logic
- **Pandas** — Data processing and analysis
- **NumPy** — Numerical computations
- **Scikit-learn** — Machine learning
- **Plotly** — Interactive visualizations
- **Streamlit** — User interface
- **Gemini AI** — Financial chatbot

## Key Learning
Through this project, I learned to integrate machine learning and generative AI into a practical application and build an end-to-end, data-driven solution.
